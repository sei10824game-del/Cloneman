# CLONEMAN — クローンマン

**パックマンの迷路で、過去の自分と共闘するタイムループ弾幕アクション。**

プレイヤーは直線に放たれる弾幕で敵の群れを殲滅していく。全ての敵を倒すと、
壊れた地形と敵がリセットされて次のラウンドへ — そのとき、**クリアしたラウンドの動きを
そっくり再現する「自分のクローン」**が次のラウンドに参戦する。ラウンドが進むほど
敵は強く、多くなる。フレンドリーファイアはなし。何ラウンド生き残れるか。

## ゲームルール

| 要素 | 内容 |
| --- | --- |
| **勝利条件** | ラウンド内の全敵を倒すとラウンドクリア。壊した地形・敵・ペレットがすべてリセットされ次のラウンドへ |
| **クローン参戦** | クリアしたラウンドの自分が、そのラウンドと**寸分違わず同じ動き・同じ弾**を再演する味方として登場。ラウンドを重ねるほどクローンが増える |
| **フレンドリーファイアなし** | クローンとプレイヤーは互いに無害。ただし**敵はクローンもプレイヤー同様に襲い**、被弾したクローンはそのラウンド限りで消滅する |
| **長いクールタイム** | 自機の弾はクールタイムが長め。クローンの弾との連携なしには戦えなくなる |
| **ラウンド成長** | ラウンドが上がるごとに敵の数が増え、HP・速度も強化される |
| **破壊可能地形** | 橙色のひび割れブロックは弾で破壊できる（+25点）。ラウンドクリアで元通りに復活 |
| **パワーペレット** | 四隅の大ペレットで6秒間パワーアップ — 連射速度UP・弾が巨大化・敵は逃げ惑う |

## 敵の種類

| 出現 | 名前 | 特徴 |
| --- | --- | --- |
| Round 1〜 | チェイサー（赤） | プレイヤーを執拗に追跡する基本ゴースト |
| Round 2〜 | スピーディ（桃） | 高速追跡。数が増えていく |
| Round 3〜 | タンク（青） | 高HP・低速。大型で弾が効きにくい |
| Round 4〜 | シューター（紫） | 直線上からプレイヤーに弾を撃ってくる |

ラウンド2から敵は「2 + ラウンド」体規模に増え、HP・速度も微増していきます。

## 操作方法

| キー | 動作 |
| --- | --- |
| `←` `↑` `↓` `→` / `W` `A` `S` `D` | 移動（パックマン方式・方向先行入力可） |
| `SPACE` / `Z` / `J` / `X` | 直線弾幕を発射（クールタイム長め・押しっぱなしで連射） |
| `P` / `ESC` | 一時停止 |
| `M` | サウンド ON/OFF |
| `Enter` | ゲーム開始 / リトライ |

## プレイ方法

静的ファイルのみで動くので、任意のHTTPサーバーで開くだけです。

```bash
# Python があればこれだけ
python3 -m http.server 8000
# → http://localhost:8000
```

```bash
# npm 経由でも可（npx http-server）
npm run start

# ブラウザのキャッシュを無効化したい開発・プレビュー時はこちら
python3 tools/nostore_server.py
```

### プレビューURLが開けないときは

`cloneman-standalone.html` — JS/CSSをすべて1ファイルにインライン化した**スタンドアロン版**です。
サーバーもプレビューも不要で、**ダブルクリック（file://）だけで遊べます**。
コードを変更した後は以下で再生成してください。

```bash
node tools/build-standalone.mjs && node tools/verify-standalone.mjs
```

## テスト

```bash
npm test            # ヘッドレス・スモークテスト（実際にプレイして全フロー検証）
node tools/fuzz.mjs 90   # ランダム入力ファズテスト
```

## 技術構成

- バニラ JS（ES Modules）+ HTML5 Canvas、ビルド不要・依存ゼロ
- 固定タイムステップ（60Hz）でシミュレーション — クローンのリプレイをフレームレート非依存で決定的に再生
- 敵AIはプレイヤー＋全クローンを始点とするマルチソースBFSの距離場で、「最も近い味方」を追う経路探索。パワーモード中はフリーに徘徊
- ラウンド中の自機の座標・向き・口パク・発射を毎tick記録し、クリア後のラウンドで完全再演
- 壁の事前レンダリング（オフスクリーンCanvasキャッシュ）、パーティクル/ポップアップ/画面シェイク演出
- Web Audio API によるプロシージャルな効果音（アセット不要）
- ハイスコアは localStorage に保存

```
├── index.html      # エントリー（HUD・タイトル/終了/ポーズ overlay）
├── style.css       # ネオンアーケードスキン
├── js/
│   ├── maze.js     # 迷路定義（25×21・左右対称）とグリッド構築
│   ├── audio.js    # Web Audio 効果音シンセ
│   └── game.js     # ゲーム本体（状態管理・リプレイ・敵AI・描画）
└── tools/
    ├── mazegen.mjs # 迷路ジェネレータ＆連結性バリデータ
    ├── smoke.mjs   # スモークテスト
    └── fuzz.mjs    # ランダム入力ファズテスト
```
