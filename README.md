# CLONEMAN — クローンマン

**パックマンの迷路で、過去の自分と共闘するタイムループ弾幕アクション。**
さらに **敵モード「天敵ゴースト」** — **通常プレイと同じルールで動くプログラムされたパックマン**（ペレットを食べ、直線弾を撃ってくる）と対戦できるモード、そして **コピーミー「自立学習モード」** — 全クローンが毎ラウンド全プレイ履歴から再学習する自律分身モードも収録。

プレイヤーは直線に放たれる弾幕で敵の群れを殲滅していく。全ての敵を倒すと、
壊れた地形と敵がリセットされて次のラウンドへ — そのとき、**クリアしたラウンドの動きを
そっくり再現する「自分のクローン」**が次のラウンドに参戦する。ラウンドが進むほど
敵は強く、多くなる。フレンドリーファイアはなし。何ラウンド生き残れるか。

## ゲームモード

タイトル画面で3つのモードを選べます。

### コピーミー — 自立学習モード（自律分身）

**強化学習ショップは存在しない**代わりに、**すべてのクローンが常に自律型擬似プレイヤーとして出撃**します。しかもラウンド開始ごとに、その時点までのあなたの全プレイ履歴（撃墜数・射撃レート・ペレット摂取率・死亡率）から学習モデルを再構築して全クローンに配布し直します — **クローンはリプレイではなく、毎ラウンド再学習するあなたの分身**です。ゴールドの概念はなく、報酬はクリアの達成感とスコアだけ。ラウンドを重ねるほど分身は賢くなります（残機3つ・敵に襲われる・フレンドリーファイアなし等のクローンルールは共通）。

### プレイヤーモード — クローンマン（弾幕シューティング）

自機で敵を殲滅し、クリアしたラウンドの動きを再演するクローンと共闘する、タイムループ弾幕アクション。上記のルール表のとおりです。

### 敵モード — 天敵ゴースト（天才パックマン狩り）

**あなたは赤い天敵ゴースト。** 迷路を疾走する**プログラムされた天才パックマン**を、触れるだけで撃破する（弾は撃てません）。パックマンはBFSの距離場でペレットを最短経路で漁り、ゴーストに追われるとパワーペレット（アイテム）を優先的に取りに行き、使用中は**あなたを狩り返す**。

| 要素 | 内容 |
| --- | --- |
| **勝利条件** | ラウンド内の天才パックマンを全て触れて撃破（+1000点・+200G／体） |
| **パックマン+1** | **パックマンを倒すと次のラウンドでパックマンの数が+1される**。増え続ける天才たちと死闘を |
| **アイテム使用中は無効** | パワーペレット使用中（赤い輪が出ている間）のパックマンに触れると**あなたがやられる** |
| **死ぬたびにラウンドが進む** | 被弾すると残機を1消費し、**次のラウンドへ進み、死んだ自分がクローンとして出撃**する（残機0でゲームオーバー） |
| **クローン** | 前ラウンドのあなたの動きを再演するゴーストの残留思念。パックマンを一緒に狩ってくれるが、パワーアップ中のパックマンにはやられる。残機3つ |
| **天才の行動** | **通常プレイのプレイヤーとまったく同じルールで自律プレイ**：ペレットを食べ、パワーペレット（アイテム）で6秒強化、**直線に弾を撃ってくる**（クールタイム長め・直進のみ・命中で残機-1）。危険時はパワーペレット優先・使用中は全力追跡 |
| **強化学習ショップ** | 敵モードの記録はリプレイ専用（RL付与の対象外） |

## ゲームルール

| 要素 | 内容 |
| --- | --- |
| **勝利条件** | ラウンド内の全敵を倒すとラウンドクリア。壊した地形・敵・ペレットがすべてリセットされ次のラウンドへ |
| **クローン参戦** | クリアしたラウンドの自分が、そのラウンドと**寸分違わず同じ動き・同じ弾**を再演する味方として登場。ラウンドを重ねるほどクローンが増える |
| **フレンドリーファイアなし** | クローンとプレイヤーは互いに無害。ただし**敵はクローンもプレイヤー同様に襲い**、被弾したクローンは残機を1消費してスタート地点からリセットされる |
| **クローンの残機** | クローンは**生まれた時点のプレイヤーの残機を引き継ぐ**（残機1でクリアしたラウンドのクローンは残機1）。**被弾・再生終了（時間切れ）のどちらでも残機を1消費してリプレイの最初から立て直す**。残機0で消滅 |
| **死亡リプレイ** | ラウンド中に倒されて復活した区間もリプレイに含まれ、クローンは**爆発→復活地点に再登場→戦闘再開**という流れをそのまま再演する（この再演で残機は減らない） |
| **長いクールタイム** | 自機の弾はクールタイムが長め。クローンの弾との連携なしには戦えなくなる |
| **ゴールド** | ラウンドクリアで**120G＋80G×(ラウンド-1)**、敵を1体倒すごとに**+4G**獲得。ゴールドは localStorage に保存され、ゲームオーバーを跨いで貯まる |
| **強化学習（RL）ショップ** | `B` キーでショップを開き、**300G**で好きなクローンに**強化学習**を付与できる。付与されたクローンは記録の再生をやめ、プレイヤーのリプレイデータから学習した"攻撃性・ペレット欲・回避本能"を頼りに自律行動する**擬似プレイヤー**へ進化する。ペレットを食べ、**正面（自分の向き）に敵がいるときだけ直線に弾を撃ち**、危険を避けて立ち回る |
| **アップグレード** | 同じショップで**永続強化（ランを跨いで有効・localStorage保存）**が買える。**上限残機+1**（今すぐ+1も獲得・400G/650G）／**攻撃力+1**（直射弾のダメージ・350G/550G/800G）／**同時発射+1**（一度に撃つ並走弾・500G/900G）／**移動速度+6%**（250G/450G）／**ゴールド獲得+25%**（300G/550G）。強化はプレイヤーと全クローンの弾に適用される |
| **RLクローンの姿** | RL化したクローンは白い縁取りと「RL·ラウンド番号」タグが付き、人間プレイヤーと同様に被弾で残機を消費する（残機3つ） |
| **ラウンド成長** | ラウンドが上がるごとに敵の数が増え、HP・速度も強化される |
| **破壊可能地形** | 橙色のひび割れブロックは弾で破壊できる（+25点）。ラウンドクリアで元通りに復活 |
| **パワーペレット** | 四隅の大ペレットで6秒間パワーアップ — 連射速度UP・弾が巨大化・敵は逃げ惑う |

## 敵の種類

| 出現 | 名前 | 特徴 |
| --- | --- | --- |
| Round 1〜 | チェイサー（赤） | プレイヤーを執拗に追跡する基本ゴースト |
| Round 2〜 | スピーディ（桃） | 高速追跡。数が増えていく |
| Round 3〜 | タンク（青） | 高HP・低速。大型で弾が効きにくい |
| Round 4〜 | シューター（紫） | 直線上からプレイヤーに弾を撃ってくる |
| Round 4〜 | フェントム（青緑） | 周期的に透明化（約1.5秒）して接近する。姿を見失ったら終わり |
| Round 5〜 | スプリッター（黄緑） | 撃破すると**スニッチ**（小型・高速チェイサー×2）に分裂 |
| Round 5〜 | ワープ（紫・渦模様） | 一定間隔でプレイヤー周辺へテレポートしてくる |
| Round 6〜 | ヒーラー（薄緑・＋印） | 近くの仲間のHPを回復し続ける。最優先で仕留めたい |

ラウンド2から敵は「2 + ラウンド」体規模に増え、HP・速度も微増していきます。ラウンド6あたりから1度に押し寄せるのは最大16体に達し、新種の比率が高まります。

## 操作方法

| キー | 動作 |
| --- | --- |
| `←` `↑` `↓` `→` / `W` `A` `S` `D` | 移動（パックマン方式・方向先行入力可） |
| `SPACE` / `Z` / `J` / `X` | 直線弾幕を発射（クールタイム長め・押しっぱなしで連射） |
| `P` / `ESC` | 一時停止 |
| `B` | 強化学習ショップを開閉（ゴールドでクローンを強化） |
| `M` | サウンド ON/OFF |
| `Enter` | ゲーム開始 / リトライ |

## プレイ方法

静的ファイルのみで動くので、任意のHTTPサーバーで開くだけです。

```bash
# Python があればこれだけ
python3 -m http.server 8000
# → http://localhost:8000
```

```bash
# npm 経由でも可（npx http-server）
npm run start

# ブラウザのキャッシュを無効化したい開発・プレビュー時はこちら
python3 tools/nostore_server.py
```

### プレビューURLが開けないときは

`cloneman-standalone.html` — JS/CSSをすべて1ファイルにインライン化した**スタンドアロン版**です。
サーバーもプレビューも不要で、**ダブルクリック（file://）だけで遊べます**。
コードを変更した後は以下で再生成してください。

```bash
node tools/build-standalone.mjs && node tools/verify-standalone.mjs
```

## テスト

npm test            # ヘッドレス・スモークテスト（実際にプレイして全フロー検証）

## 技術構成

- バニラ JS（ES Modules）+ HTML5 Canvas、ビルド不要・依存ゼロ
- 固定タイムステップ（60Hz）でシミュレーション — クローンのリプレイをフレームレート非依存で決定的に再生
- 敵AIはプレイヤー＋全クローンを始点とするマルチソースBFSの距離場で、「最も近い味方」を追う経路探索。パワーモード中はフリーに徘徊。新種は「フェントム＝周期的に透明化」「ワープ＝プレイヤー周辺へテレポート」「ヒーラー＝近距離の味方HP回復」「スプリッター＝撃破でスニッチ2体に分裂」といった固有行動を持つ
- 敵モードの天才パックマンは、ペレット全域を始点とするBFS食場＋パワーペレット専用BFS場＋ゴースト距離場の3つを見比べて最適に立ち回る（追われるとパワーペレットへ直行し、使用中は距離上昇方向＝ゴーストへ下降）
- ラウンド中の自機の座標・向き・口パク・発射・死亡タイミングを毎tick記録し、クリア後のラウンドで完全再演（倒された復活も爆発→再登場で再現）
- 「強化学習」を買うと、クローンはリプレイから推定したスタイルパラメータ（攻撃性＝射撃レート・ペレット欲＝摂取率・回避本能＝死亡率）で迷路を自律探索・射撃・回避する"擬似プレイヤー"に変貌。決定論的な再演ではなく、状況に反応して動くため同じ記録でも毎回異なる動きになる。射撃は自機と同じ制約（正面に敵がいるときだけ）に従う
- 壁の事前レンダリング（オフスクリーンCanvasキャッシュ）、パーティクル/ポップアップ/画面シェイク演出
- Web Audio API によるプロシージャルな効果音（アセット不要）
- ハイスコアとゴールドは localStorage に保存

```
├── index.html      # エントリー（HUD・タイトル/終了/ポーズ overlay）
├── style.css       # ネオンアーケードスキン
├── js/
│   ├── maze.js     # 迷路定義（25×21・左右対称）とグリッド構築
│   ├── audio.js    # Web Audio 効果音シンセ
│   └── game.js     # ゲーム本体（状態管理・リプレイ・敵AI・描画）
└── tools/
    ├── mazegen.mjs # 迷路ジェネレータ＆連結性バリデータ
    ├── smoke.mjs   # スモークテスト
    └── fuzz.mjs    # ランダム入力ファズテスト
```
